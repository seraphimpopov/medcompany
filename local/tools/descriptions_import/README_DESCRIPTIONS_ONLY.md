# Загрузка только отсутствующих описаний в 1С-Битрикс

Пакет заполняет описания товаров и **не работает с изображениями**.

## Что подготовлено

- Всего строк товаров в исходной YML-выгрузке: **10359**.
- С артикулами: **8207**.
- Без артикула: **2152**.
- Взято содержательных описаний из исходной выгрузки: **4808**.
- Подготовлено нейтральных описаний по названию, категории, артикулу и характеристикам: **5551**.

Скрипт проверяет реальные поля товара в Битриксе и заполняет только пустые `PREVIEW_TEXT` и `DETAIL_TEXT`. Существующие описания не перезаписываются.

## Файлы

- `descriptions_all_products.json` — данные для импорта по всем товарам.
- `import_missing_descriptions.php` — импортёр для Битрикса.
- `detect_iblock_and_article_property.php` — показывает ID инфоблоков и свойства артикула.
- `descriptions_review.csv` — полная таблица для проверки текстов.
- `generated_descriptions_review.csv` — только автоматически сформированные описания.

## Как определяется товар

1. Точное совпадение по артикулу.
2. Если один артикул найден у нескольких товаров — дополнительно проверяется точное название.
3. Для товаров без артикула используется только точное совпадение названия.
4. Если совпадений несколько, товар пропускается и попадает в лог как `AMBIGUOUS_*`.

## Установка

Загрузить в папку сайта:

```text
/local/tools/import_missing_descriptions.php
/local/tools/detect_iblock_and_article_property.php
/local/tools/descriptions_all_products.json
```

Сначала можно определить нужный инфоблок:

```bash
php /home/USER/SITE/public_html/local/tools/detect_iblock_and_article_property.php
```

Открыть `import_missing_descriptions.php` и указать ID инфоблока каталога:

```php
'IBLOCK_ID' => 0,
```

Лучше заменить `0` на реальный ID инфоблока. Это ускорит импорт и исключит совпадения с другими инфоблоками.

## Первый запуск — только проверка

По умолчанию включено:

```php
'DRY_RUN' => true,
```

Запуск из корня сайта или по абсолютному пути:

```bash
php -d memory_limit=1024M /home/USER/SITE/public_html/local/tools/import_missing_descriptions.php
```

После завершения открыть:

```text
/local/tools/descriptions_import_log.csv
```

Основные статусы:

- `DRY_RUN_OK` — описание будет добавлено.
- `ALREADY_FILLED` — описание уже есть, товар не меняется.
- `NOT_FOUND` — товар не найден.
- `AMBIGUOUS_ARTICLE` / `AMBIGUOUS_NAME` — найдено несколько товаров, автоматическое изменение пропущено.
- `INVALID_DESCRIPTION` — исходный текст слишком короткий.

## Реальная загрузка

После проверки лога изменить:

```php
'DRY_RUN' => false,
```

И повторить запуск.

## Запуск частями

На слабом сервере удобно обрабатывать по 500 товаров:

```php
'LIMIT' => 500,
'START_FROM' => 0,
```

Затем менять `START_FROM`: `500`, `1000`, `1500` и так далее.

## Безопасность

Скрипт:

- не обновляет картинки;
- не меняет цены, названия, разделы и свойства;
- заполняет каждое поле описания только тогда, когда оно пустое;
- повторный запуск безопасен;
- записывает все действия и пропуски в CSV-лог.
